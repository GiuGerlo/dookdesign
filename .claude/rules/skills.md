# Skills del proyecto

> Skills globales instalados relevantes para dookdesign. El agente los usa cuando aplica.
> Nota: los skills viven en `~/.claude/skills` / plugins (globales), no en el repo. Esto es solo la referencia de cuáles usar acá.

## Diseño / UI (fase con Agustín + construcción visual)

- **frontend-design** — construir UI distintiva, anti-slop. Base de todo lo visual.
- **web-design-guidelines** — review de UI: accesibilidad, UX, buenas prácticas. Correr al cerrar pantallas.

## Stack (Next.js 16 + Supabase)

- **vercel-react-best-practices** — perf de React/Next.js: componentes, data fetching, bundle. Al escribir/refactorizar TSX.
- **supabase-postgres-best-practices** — perf y diseño de schema Postgres. Al modelar tablas o escribir queries en Supabase.

## Metodología / soporte

- **find-skills** — descubrir/instalar skills nuevos cuando falta una capacidad ("¿hay skill para X?").
- **caveman** / **caveman-commit** — comunicación comprimida + mensajes de commit Conventional.
- **ponytail** — solución mínima, anti over-engineering.
- **security-review** — audit al cerrar cada fase.
- **context7-mcp** — docs actualizadas de librerías.

## Pendientes de instalar (opcional, cuando hagan falta)

- **brainstorming** — cambio creativo → spec. Referenciado en `CLAUDE.md` / `docs-workflow.md`.
- **writing-plans** — spec aprobado → plan accionable.
- **design-motion-principles** — principios de animación/motion (útil para las transiciones del portfolio).
